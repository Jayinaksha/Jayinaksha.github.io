Newsroom

No editor — only rules anyone can read

Citizens file reports and evidence. A desk corroborates them against each other and against official sources, publishes only what clears a published ladder, and posts a visible correction when later evidence turns. A language model ranks and reconciles — it never decides what is true.

§ 01

From a report to the feed

Citizen reports and official feeds meet in one claims ledger; the ladder is pure code over it.

verify_claims.py — the whole decisiondeterministic
TIER_COMMUNITY = 3
TIER_NEWS      = 10
TIER_URGENT    = 50
OFFICIAL = {"pib_en", "rbi", "sebi", "mygov_consultations"}
MIN_PRESS_SOURCES = 2

# citizens = distinct submitter hashes, never raw counts
if official:                      return "official"
if citizens >= TIER_URGENT:      return "urgent"
if citizens >= TIER_NEWS:        return "news"
if citizens >= TIER_COMMUNITY:   return "community_report"
if press_families >= MIN_PRESS_SOURCES: return "news"
return None  # held_observation
Honest counting

One device counts once

Only distinct submitters count; a coordinated burst from one source is one citizen.

Incentives

Points follow the evidence

Earned when a report is corroborated, lost when it is contradicted. Credibility buys processing priority — never verification.

Privacy

The desk never sees who you are

No contacts, passwords or platform IDs cross into the desk — only salted hashes and a credibility band.

§ 02

Corrections are first-class

When verified evidence later contradicts a published story, a deterministic check posts a correction onto that story’s visible history. Nothing is silently edited. The only human control is an operational kill switch — pause or retract — never an editorial one.

An AI anchor reads the verified news aloud, and every sentence it speaks is journaled, linked to the evidence behind it.
